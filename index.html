An AI agent that works in your terminal, on any model.

Viper reads and edits your files, runs commands, searches the web, drives a browser and works with GitHub. It runs on Ollama, OpenRouter, Hugging Face or Claude through one OpenAI-compatible interface, and it asks you before anything risky.

System design

How the pieces fit together

The CLI streams a model response, collects tool calls, vets them through security checks, runs them in parallel and feeds results back until the model stops asking for tools. Every layer is a small module.

■ green: core agent loop▭ dashed amber: security boundary▭ dashed grey: swappable layer
How it works

One turn of the agent loop

Each message you send can trigger several rounds. The model answers, asks for tools, Viper runs them and returns the results, and this repeats until the model replies with plain text.

1 · input

Check what you typed

Your message is scanned for SSNs, card numbers, emails, API keys and passwords. If any appear, you confirm before it goes to the provider.

2 · stream

Stream the answer

The reply streams into a live panel. Tool calls arrive in pieces and are assembled as they stream. If a provider has no tool support, Viper retries without tools.

3 · vet

Vet before running

Shell commands and Python code are matched against danger patterns. Anything suspicious stops and asks you for a yes or no.

4 · act

Run tools in parallel

Independent calls run on a thread pool of up to four workers. A single call shows a live spinner with its timing.

5 · scan

Check the results

Output is checked for PII and prompt injection, truncated to 8,000 characters, and wrapped in an untrusted tag so the model treats it as data.

6 · keep

Manage context

The oldest messages are dropped once context passes 100,000 characters. Sessions save on exit (encrypted with the crypto extra) and resume with --resume.

Features

What it can do

All of this lives in a handful of Python files you can read in an afternoon.

Four providers, one client

Ollama, OpenRouter, Hugging Face and Claude via OpenRouter, all through the OpenAI SDK. Switch model mid-session with /model.

Files and shell

Read, write, edit and list files. Run shell commands with timeouts, in the working directory you choose with --cwd.

Python execution

Run code with optional pip packages, locally or in an isolated e2b sandbox when you set the sandbox flag.

Web and browser

DuckDuckGo search, HTTP fetch with custom methods and headers, and a Playwright browser that can click, type and take screenshots.

GitHub built in

Ten tools to read repos, list and comment on issues, open pull requests, update files and clone.

Multi-agent mode

An orchestrator plans subtasks, runs up to four workers in parallel with retries, and merges their answers. Trigger it with /multi, or let the model call spawn_agents.

Visible thinking

A think tool lets the model reason before acting. Toggle the display with /think.

Sign in with Google

One click on a hosted page. The terminal receives the session on a one-shot localhost server and checks it with Supabase. Keys and session stay on your machine, encrypted.

Free tier

Try 3 queries without signing in. Signed-in users get 3 free sandbox sessions on a shared E2B key, then add their own with /e2b.

Slash commands

/clear /model /tools /save /cwd /tokens /think /multi /pii /e2b /help

Safety

Guardrails that run before and after every tool

An agent with a shell is only useful if you can trust what it does. Viper puts a check on both sides of every action.

before

Dangerous commands

Matches rm -rf, Remove-Item, DROP TABLE, mkfs, shutdown, plus curl-pipe-bash, base64-to-shell, reverse shells, fork bombs and secret exfiltration via curl.

before

Risky Python

Flags ctypes, __import__, winreg and exec or eval on encoded payloads.

before

Paths and URLs

Blocks path traversal, ~/.ssh, ~/.aws, .env and key files. Resolves hostnames and rejects private IPs, cloud metadata endpoints and non-HTTP schemes (SSRF).

after

Prompt injection

Twelve pattern families, such as "ignore previous instructions" and fake chat-template tokens. A hit asks you before the content reaches the model.

after

Untrusted output tags

Output from the web, files and shell is wrapped in trust="untrusted" so the model knows it is data, not instructions.

always

Limits and encryption

200 tool calls per session, 50 rounds per turn, and, with the crypto extra, saved sessions encrypted with Fernet under a key kept in ~/.viper.

Why it is not a demo

Viper vs. a typical tutorial agent

Most example agents are a loop around one API call. These are the parts they leave out.

Get started

Install and run

Requires Python 3.11 or newer. Installing adds a viper command to your terminal.

1Run the one-line installer

The script checks for Python 3.11+, installs viper-agent[all] (PyPI first, GitHub source as fallback) and downloads Chromium for the browser tool. It installs into the Python you run it with, so activate a virtual environment first if you want isolation. You can read the script before running it: install.sh, install.ps1.

Windows PowerShell
iwr -useb https://raw.githubusercontent.com/arpitmishra61/Viper-Agent/master/install.ps1 | iex
macOS / Linux
curl -fsSL https://raw.githubusercontent.com/arpitmishra61/Viper-Agent/master/install.sh | bash

2First run: sign in and add your key

Run viper. Choose Sign in with Google. Your browser opens, you pick an account, and the terminal continues as soon as you are back. Or pick Continue free for 3 queries. Then pick a provider with the arrow keys and paste your own API key. Viper checks the key before saving it. Next time it shows logged in as you@gmail.com and the same provider menu.
